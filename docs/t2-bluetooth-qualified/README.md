# Bluetooth startup reference fixtures

These files preserve the qualified startup arrangement used to develop and test the transactional Bluetooth installer. The installer tests consume them to check adoption of existing installations and parity with the readiness algorithm. They are intentionally retained as reference fixtures.

Use the [current installer design](../t2-bluetooth-installer.md) and [user setup commands](../../manual/t2-bluetooth.md) for installation. The maintained runtime helper is [gate.py](../../install/hardware/apple/t2-bluetooth/gate.py); do not deploy this reference directory manually.
